# saxipatel-dev.github.io

My personal portfolio, live at **https://saxipatel-dev.github.io**.

The site is a scroll-driven transit map of my career: a train rides "Line S" from Gujarat, across the Atlantic, to New Jersey, stopping at each internship, degree and project. FlowOps and ReturnDesk each get their own branch line with a small working model of their hardest problem, and there's a terminal for anyone who'd rather type.

Built by hand with HTML, CSS and the Canvas API, with no frameworks or build step.
